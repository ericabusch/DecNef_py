## Changes made 2026-10-23/24 (both repos; everything is on `master` here and on `main` in affRT_study)

### DecNef_py (master @ 7db106a)
- `decnef.display.build_window` chooses the screen explicitly (`screen=`, `borderless=`), logs the
  screens pyglet found and the choice, warns under Wayland. On Linux the second-screen window is
  borderless at that screen's own offset/size: a `fullscr` window on screen 1 lands on the primary
  screen with pyglet/X11, which is why the task opened on the laptop panel instead of the projector.
  `window_kwargs()` is the pure choice, covered by `tests/decnef/test_display_window.py`.
- Feature branch merged and deleted; work directly on master from now on (CLAUDE.md, local only).

### affRT_study (main @ ea3fd58)
- Laptop install: `pythonpath = ["."]` for pytest; tests ignore the shell's `AFFRT_MACHINE`.
- Scanner profile writes under `/SSD2/erica/affRT_study/data` (gitignored); stimuli stay in the checkout.
- Clips come from `CowenKeltnerEmotionalVideos`; `make_stimlists` skips any clip a rater excluded in
  `clip_durations.csv` (241 excluded, 1955 usable). `check_setup.py` reports usable clips, each movie
  file, screen indices/offsets, and the session type (Xorg vs Wayland).
- Movie seek bug: PsychoPy 2026.2 discards `seek()` on a never-played MovieStim, so any run starting
  mid-file played from 0 or showed nothing. Fixed by parking the movie (play/seek/pause) at load.
- Clip playback: all 36 decoders were opened at once and never freed (`MovieStim.unload()` is broken
  in 2026.2), starving the later ones ("Failed to return a frame"). Now each clip is loaded one block
  ahead and its decoder closed after its block; opens retry 5x; a clip that still fails never aborts
  the run and is recorded in `task_log.json` (`playback_problems`) and `events.tsv` (`stim_end_s`).
  All 2196 clips open cleanly in PsychoPy when decoders are closed; a 36-clip run shows no problems.
- Movies: two runs per movie, one whole file per run (witness 965/861 s, sprout 605/717 s, file length
  rounded up to a whole TR); `max_run_s` 1100 (leaves room for the 82 s of eye-tracking grid blocks).
- `affrt.display.screen` forces a screen index; passed through to `build_window` by all launchers.
- Trigger key stays `s` (same as the KoreanLearning scripts on this laptop).
